# Marketing — UI kit

A single-page marketing/docs home for SEJFA. Demonstrates the *editorial* use of the design system: Fraunces display, paper background, a vault-dark terminal inset, a 6-node loop visualization, feature grid with mono glyphs (no Lucide — pure text characters), stats row, a dark quote break, and a CTA.

Sections, top → bottom:
1. **Nav** — mono wordmark, links, primary CTA
2. **Hero** — display headline with italic green accent, terminal inset showing a live loop run
3. **The Loop** — the 6-node stepper with the active node highlighted dark
4. **Why it sticks** — 6 feature tiles, each anchored by a single Unicode glyph
5. **Stats** — 4 big numbers in loop-green mono
6. **Quote** — dark band, display serif, the brand's tagline
7. **CTA** — display headline + primary button

All values, copy, and numbers come from the SEJFA project report. Fraunces is reserved for this surface — the app and agent-console never use it.
